AAC Programming Assignment 1 - 26 questions from the supplied image

Each question is a separate C source file. Q27 is an additional benchmark program for the assignment note requesting execution-time comparisons on random arrays of 1000, 2000, and 5000 elements.

Compile an individual program with GCC:
    gcc Q01_Factorial.c -o Q01_Factorial
Run on Windows:
    Q01_Factorial.exe
Run on Linux/macOS:
    ./Q01_Factorial

Programs use standard C (C11-compatible) and contain no code comments.
Input is validated where practical. Recursive Fibonacci is limited to n <= 40 because the direct recursive algorithm is slow.
